## Slide 3 — The Landscape: Where Executive Search Sits Today

Most firms we meet are at one of these stages:

| Level | What it looks like |
|-------|-------------------|
| **Assisted** | Partners use ChatGPT for drafting JDs, emails, candidate summaries |
| **Copilot** | Tools suggest CRM updates or search queries — humans approve every step |
| **Autopilot** | Agents capture meetings, log CRM entries, flag exceptions — humans review |
| **Self-Driving** | Agents proactively find pipeline gaps, run searches, suggest actions |

The value gap is between Assisted/Copilot and Autopilot. Most firms haven't crossed it yet.

**Visual pointers:** Four-row vertical ladder/staircase. Top 2 rows in muted grey, bottom 2 in accent colour. Arrow pointing from Copilot to Autopilot labelled "the gap." Clean, minimal — no images.

## Slide 4 — The BuildWise Playbook: Phase 1 → Phase 2 → Phase 3

Here's how every engagement works. Three phases, your pace.

**Phase 1 — Agent Workforce Audit**
We map your current workflows, identify where admin drag is highest, and design your agent org chart.
→ You receive: baseline KPIs, process documentation, recommended agent roles, and a Phase 2 proposal.
→ **No commitment beyond this point unless Phase 2 is accepted.**

**Phase 2 — Deploy Agent #1**
We deploy one agent for a single, narrow role. 30-day measured pilot.
→ Month 1: bundled setup + deployment + onboarding support.
→ Month 2 onward: ongoing monthly retainer with **tacite renewal** — auto-renews unless you cancel with 14 days' notice.
→ **If the ROI isn't there, you cancel. If it works, you continue.**

**Phase 3 — Scale**
Add Agent #2, Agent #3. Same playbook, adjacent roles, compounding savings.
→ Each new agent is a hire with lower setup cost (config, not rebuild).

All three phases follow the same principle: **each agent is a hire, not a project.**

**Visual pointers:** Horizontal timeline with 3 blocks (Phase 1 → Phase 2 → Phase 3). Each block has: title (top), 1-line scope (middle), "commitment" note (bottom). Phase 1 box smallest, Phase 2 medium, Phase 3 widest (visualising growth). Subtle arrow labels: "You decide." No images.

## Slide 5 — Case Study

**Client A** — Mid-size executive search firm, ~10 consultants
- 200+ applications received daily across email and internal database
- Consultants manually copy-pasting between tools to process candidates
- **Solution:** Candidate matching agent connected to their internal database
- **Flow:** Incoming CV → agent extracts key data → matches against active roles → returns ranked shortlist
- **Status:** Phase 1 audit completed → Phase 2 deployed (ongoing)

**Client B** — Large executive search firm, Salesforce-based CRM
- Consultants logging CRM entries hours or days after meetings
- Inconsistent data quality, lost commercial intel
- **Solution:** CRM capture agent accessible via Telegram
- **Flow:** Consultant sends voice note or text → agent creates CRM record in real time
- **Status:** Phase 1 agreed — agent scoped and ready for deployment

**Visual pointers:** Two-column layout — Client A | Client B. Each column: firm type, pain point, solution (bold), flow, status. No logos, no real names, no internal data. Clean and professional.
